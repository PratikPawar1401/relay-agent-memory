- Organizer requirements cite the official event pages.
- Framework capabilities cite their official repositories or documentation.
- Relay behavior is described as verified only when covered by a recorded run or automated check.
- The exact Cognee source revision, file hashes, license, and modifications are recorded in [`NOTICE.md`](../../NOTICE.md) and [`PROVENANCE.json`](../../src/relay/_vendor/cognee/PROVENANCE.json).
